Architecture

Four modules, 24 apps, one rule.

Local-first, zero-tracking, no Google Play Services. This page is how the suite is actually put together, including where the build stands today.

The apps Real status

1 · Layers

The foundation sits on nothing

Everything in the suite sits on these four repositories, and the apps sit on top of them.

F4 · nijatva-suite App index, release downloads, self-hosted F-Droid style repository
F1 · nijatva-coreCompose UI, SAF, backupDesign system and shared helpers
F2 · no-gms-checkGradle plugin, CI actionFails the build on any GMS artefact
F3 · nijatva-designIcons, templatesKeeps 24 repos looking like one suite
Phase 1 · 5Calc, Clock, Notes, QR, Files
Phase 2 and 3 · 15Gallery, Music, Recorder, PDF, Device Info, Weather, Dialer, Contacts, SMS, Calendar, Camera, Expenses, Tasks, RSS, Vault
Phase 4 · 4Keyboard, Launcher, Browser, App Manager

F1, F2 and F3 are not decoration. If nijatva-core lands late, twenty apps grow twenty copies of the same Storage Access Framework helper. If no-gms-check lands late, the no-GMS claim stops being a build failure and becomes a promise.

Two rules are visible in the skeleton itself

The privacy state is on the screen, not buried in settings. A banner states whether storage access is granted and whether the app holds INTERNET. For the keyboard and the calculator the honest answer is "not requested", and saying it out loud is the product.

The middle bar reads Vault / Local, never Cloud. There is no sync target to put there.

5 · Corrections

Two mistakes, recorded

Kept on the page so the same two do not come back.

nijatva-core does not sync anything

The first draft described core as "Compose UI + SAF + Sync". There is no sync in a local-first suite. Core carries the design system, SAF helpers, a text-to-speech wrapper, encrypted preferences and local backup and restore.

AdMob is advertising, not analytics

The draft grouped "AdMob / Crashlytics" under one heading. They are two separate bans: no ad SDK, and no analytics SDK. The second is the one people forget, because a crash reporter usually ships telemetry along with it.

Repository naming

nijatva-<app>, lowercase and hyphenated. Foundation repos follow the same rule.

Package name

in.nijatva.<app>, fallback com.devira.<app>. Locked before the first release.

Display name

Nijatva <App>, one prefix everywhere, never abbreviated.
