Foundation

The shared pieces

Four repositories that every app is built on. All four exist today and contain a README only — the code is the next step, and it comes before the apps.

nijatva-core

Shared libraryREADME only

Compose design system, Storage Access Framework helpers, text-to-speech wrapper, encrypted preferences, local backup and restore.

Repository

no-gms-check

Build guardREADME only

A Gradle plugin and CI action that fails the build if a Google Play Services or Firebase artefact slips in.

Repository

nijatva-design

Brand assetsREADME only

The icon set, screenshot templates and README template that keep 24 repositories looking like one suite.

Repository

nijatva-suite

Meta repositoryREADME only

The app index, release downloads and the self-hosted F-Droid style repository.
