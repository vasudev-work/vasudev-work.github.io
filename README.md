# The old address

The Nijatva site moved to **https://nijatva.github.io/** on 18 November 2026.

This repository exists so the old address keeps working. It publishes one small
page that sends a visitor to the new site, a 404 that carries the path across,
and a robots.txt that points a crawler at the new sitemap.

Nothing is served from here beyond that redirect. The site itself, its pages and
its history live in `nijatva/nijatva.github.io`.
